## 每個主題都一樣的三件事

1. **`myid.py`（身份指紋）**：兩片板子都要存一份，只改前三行（學號、組號、A 或 B）。每支上機程式第一行都是 `import myid`，截圖要看得到它印出的那一行和右下角的日期時間，看不到的那一題不計分。
2. **`cfg.py`（本組參數）**：SSID、密碼、頻道、埠號、主題名稱都由組號自動算，原封不動存到兩片板子即可。
3. **`mysecret.py`**（主題 14、16、17）：只是範本，填好老師給的種子與密碼之後**不要上傳、不要放進作業 zip**。

主題 5、8、10、16 用到的 `wsnproto.py`、`wsntree.py` 放在 Pico 上；`wsn_decode.py` 在電腦上用 Thonny 打開按執行，把 B 板印出的十六進位貼上去，就能看到一層一層的欄位解析。Pico 記憶體不夠時改用 `mpy/` 資料夾裡的 `.mpy`。
