# Wi-Fi 兩板對傳：範例程式

無線感測網路協定與應用（Pico 2W 版）｜搭配投影片「Wi-Fi 兩板對傳」

感測節點（830 孔麵包板）量溫濕度、光照、土壤溼度，用 Wi-Fi＋UDP 每 2 秒送一筆 JSON 給收集端（400 孔麵包板）；收集端自己開 Wi-Fi 當基地台，收到資料就顯示在 OLED、超過門檻亮紅燈嗶兩聲、太久沒收到亮黃燈，最後用序號算封包送達率。

## 開始之前

1. `myid.py`：第 4 行改成組長學號。**兩片板子都要存一份**（上次加密與解密存過的板子沿用即可）。
2. `cfg.py`：第 1 行改成組號，**兩片板子都要存一份**，組號要一樣。第 2、3 行填手機熱點的名稱和密碼（練習 2 用，收集端那片要填）。
3. 存到板子的方法：Thonny 開啟檔案 → 檔案 → 另存新檔 → Raspberry Pi Pico → 檔名照原本的名字。

每支程式第一行都是 `import myid`，Shell 第一行會印出身份指紋（組長學號｜板子序號｜Wi-Fi MAC）。截圖要看得到這一行。

## 預設名稱和密碼（第 5 組範例，05 換成你們的組號）

| 用在哪裡 | 名稱 | 密碼 |
|---|---|---|
| 手機熱點（練習 2） | 照你的手機（`cfg.py` 第 2 行 `SSID`） | 照你的手機（`cfg.py` 第 3 行 `PASSWORD`） |
| 收集端的 Wi-Fi（練習 3～7） | `PicoAP-G05` | `wsnpico05` |
| 收集端 IP | `192.168.4.1` | — |
| UDP 埠號 | `5005`（5000＋組號） | — |

手機熱點不用改名，把手機上的名稱和密碼抄進 `cfg.py`，大小寫、空格、中文都要一模一樣；名稱有彎的撇號（例如 `Ming’s iPhone`）時，從 `02_wifi_hotspot.py` 印出的清單複製貼上。熱點一定要用 **2.4 GHz**：Android 頻段選 2.4 GHz（Pixel 打開「延伸相容性」）；iPhone 打開「最大化相容性」，熱點名稱就是「設定 › 一般 › 關於本機 › 名稱」。

## 接線

| 板子 | 模組 | 接法 |
|---|---|---|
| 感測節點 | 電源軌 | 3V3(OUT) 第 36 腳 → ＋軌、GND 第 38 腳 → －軌，上下電源軌用兩條跳線接通 |
| 感測節點 | 電容式土壤溼度 | VCC → ＋軌、AOUT → GP26（第 31 腳）、GND → －軌 |
| 感測節點 | BH1750 | VCC → ＋軌、GND → －軌、SCL → GP5（第 7 腳）、SDA → GP4（第 6 腳），ADDR 不接 |
| 感測節點 | DHT11 | VCC → ＋軌、DATA → GP15（第 20 腳）、GND → －軌 |
| 收集端 | 電源軌 | 同感測節點 |
| 收集端 | OLED 0.96 吋 | VCC → ＋軌、GND → －軌、SCL → GP5、SDA → GP4 |
| 收集端 | RGB LED（共陰） | R → GP6（第 9 腳）、G → GP7（第 10 腳）、B → GP8（第 11 腳）、－ → －軌 |
| 收集端 | 有源蜂鳴器 | VCC → ＋軌、I/O → GP11（第 15 腳）、GND → －軌 |

所有模組都接 3.3 V。I2C 位址：BH1750 是 0x23、OLED 是 0x3C。

## 檔案

| 檔案 | 跑在哪片 | 內容 | 練習 |
|---|---|---|---|
| `myid.py` | 兩片都存 | 身份指紋 | — |
| `cfg.py` | 兩片都存 | 組號、手機熱點名稱和密碼、收集端名稱和密碼、埠號；`start_ap()` 開收集端 Wi-Fi | — |
| `01_check_node.py` | 感測節點 | I2C 掃描、三個感測器各讀 5 次、記下土壤 DRY／WET | 1 |
| `01_check_collector.py` | 收集端 | I2C 掃描、RGB 紅綠藍、蜂鳴器嗶兩聲 | 1 |
| `02_wifi_hotspot.py` | 收集端 | 掃描附近 Wi-Fi、連手機熱點、印 IP 和 RSSI、`mip` 安裝 ssd1306 | 2 |
| `03_collector_ap.py` | 收集端 | 開 AP（PicoAP-G05）、UDP 在埠號 5005 等資料 | 3 |
| `04_node_send.py` | 感測節點 | 連上收集端，每 2 秒送一筆 JSON（含序號），斷線自動重連 | 4 |
| `05_collector_oled.py` | 收集端 | 收到的資料顯示在 OLED | 5 |
| `06_collector_alert.py` | 收集端 | 綠燈正常；溫度 > 30 °C 或土壤 < 30 % 紅燈嗶兩聲；6 秒沒資料黃燈 | 6 |
| `07_collector_pdr.py` | 收集端 | 用序號算送達率，OLED 顯示 PDR 和 RSSI | 7 |

## 兩片板子同時跑

- **兩台筆電**（建議）：一台接節點、一台接收集端，兩邊的 Shell 都看得到。
- **只有一台電腦**：收集端的程式另存成板子上的 `main.py`，插 USB 電源就會自動執行；Thonny 接節點跑 `04_node_send.py`。Thonny 一連上某片板子，就會停掉那片正在跑的程式。

## 練習 7 距離實驗

1. `04_node_send.py` 的 `INTERVAL` 改成 1，另存成節點上的 `main.py`，接行動電源帶出去。
2. 收集端留在教室跑 `07_collector_pdr.py`；每換一個位置按 Stop 再執行，重新算。
3. 每個位置停 30 秒以上，記下應收、收到、PDR、RSSI；至少量 4 個位置。
